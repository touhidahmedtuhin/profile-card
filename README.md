# 💻 SimpleCard — React + Tailwind CSS Profile Cards

![alt text](image.png)

A clean and modern **developer profile card** project built using **React + Vite** and **Tailwind CSS**.  
This project showcases how to design reusable, responsive, and visually appealing profile components for developers or team members.

---

## ✨ Features

- ⚡ Built with **React + Vite** for fast development and HMR  
- 🎨 Styled using **Tailwind CSS** for utility‑first design  
- 🧩 Reusable **Card Component** with props for dynamic data  
- 📁 Data loaded from a local **JSON file**  
- 🖼️ Profile images served from the **public/images** directory  
- 🔗 Includes social icons, buttons, and follower stats
